# سامانه آفلاین گزارش فعالیت

نسخه اولیه Flutter برای ثبت فعالیت کارشناسان و ورود فایل گزارش در پنل مدیر.

## اجرا
1. Flutter SDK را نصب کنید.
2. در پوشه پروژه اجرا کنید:
   flutter pub get
3. برای اجرای اندروید:
   flutter run
4. برای ساخت APK:
   flutter build apk --release

## امکانات نسخه اولیه
- ثبت فعالیت کارشناس
- دیکشنری فعالیت‌ها
- ذخیره محلی
- خروجی JSON
- اشتراک‌گذاری فایل گزارش
- ورود فایل گزارش در پنل مدیر
- جلوگیری از ورود رکورد تکراری بر اساس شناسه گزارش
- آمار اولیه مدیر
